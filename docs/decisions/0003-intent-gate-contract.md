# ADR 0003 — 意图门的契约与回滚条件

- 日期：2026-09-21
- 状态：**已采纳**（用户 2026-09-21 逐条确认 grill 轮的 Q3–Q14）
- 前置阅读：`docs/pitfalls.md` #19（口径）/ #20（可强制点）/ #23（读法）；本文只回答**为什么这样定、
  否决过什么、什么时候回滚** —— **口径不在这里复制第二份**。

## 背景

门的契约此前散在三处：persona（规则）、插件（提醒与拒绝的文案）、`HANDOFF.md`（开闸前置与回滚条件）。
而 `HANDOFF.md` 在本仓是**临时交接件**（可整份重写、无人引用）⇒ 把安全阀放在会被重写的文件里，
等于没有安全阀。

## 决定

1. **一个口径，三个读者**：persona 的模板、插件的提醒 / 拒绝、reader 的合规分子共用同一个判据
   （① 存在：门行位于承载首个行为动作的那条消息、且为该消息首行）。口径的唯一登记处是
   `pitfalls.md` #19；三处漂移由 `verify-intent-gate-watchdog.cjs` 的契约一致性（D）与
   `verify-ptc-roles.cjs` 的断言钉住。
2. **闸门是「行为纠正」，不是「位置警察」**：`enforce` 下每轮最多拒一次，判据是「本轮出现过门行」
   （实现上 `declSeq <= carrier`，而 `carrier` 取「最后一条 assistant 消息」的序号 ⇒ 只要声明被记上
   就一定成立）。它**不**强制 ① 的位置：被拒后补行重发的轮次在 ① 口径下仍记 ✗（#19 的读法注记）。
   这是有意的 —— ① 是度量，闸门是纠偏，两者可以同时为真。推论：拒绝理由里「门行晚了」那一支
   **今天不可达**（`declSeq` 一旦被记上就必然 `<= carrier`），它保留为状态真变化时的正确文案，
   单测只钉可达的那一支。
3. **模式进数据面**：`config.gate` 写错会静默落到 observe（fail-safe），而本部署没有日志通道（#9）
   ⇒ 插件每**会话**注入一行 `[intent-gate-watchdog] mode=enforce|observe`；reader 拿它与
   `preset/<id>/agent.cordis.yml` 的**声明**对照，不一致 ⇒ ✗ FAIL（缺席只作观察：本会话可能挂载于
   标记引入之前，判据见 #A 节的「重新挂载」）。
4. **回滚条件（唯一登记处 = 本文）**：观察期判据曾是「注入通道里出现过 `RACE_REPORT`」，但 enforce
   之后 `wouldDeny && !denied` 恒不成立 ⇒ 那条报告**永不注入**。改判为它的镜像：
   **假拒候选 = 被拒过的轮最终仍判 ① 合规**（插件注入 `FALSE_DENY`；reader 从**既有事件**独立算出
   同一个数，打印为 `闸门拒绝: … ｜ 假拒候选 n`）。**读到 n > 0 ⇒ 改回 `observe`**，并在确认
   「有没有一次真正的重新挂载」（#A 节）之后重跑。

## 否决过的选项

- **proactive 提醒**（每轮开轮时先注入一行，替代「被拒 → 补行 → 重发」的往返）：代价是每轮永久落库一行
  （#19 的 7 行 → 3 行教训），而拒绝实测很少（本场 1 次 / 3 轮）⇒ **否决**。
- **把闸门收紧到 ① 的位置**（用该次调用真正的载体，而不是「最后一条消息」）：会让「先只读侦察、补行、
  再动手」这种合规形态被拒；且 #17 的载体耦合已被判为**口径产物**而非模型漏行 ⇒ **否决**。
- **用正则判「模型是无视还是没看见」**：内容质量不可从数据面机械判定，误伤面更大 ⇒ **否决**
  （同 #16 的取舍：内容质量只能靠 prompt 侧）。
- **把「被拒后仍无门行继续」做成注入记录**：该事实已完全可从**既有事件**推出（拒绝 seq + 同轮后续
  事件）⇒ 交给 reader 的读数，不新增永久落库的消息。Q3② 据此换了实现方式，**判据不变**。

## 后果

- 改插件文案要**同时**改 persona 与单测（D 契约 + 集合相等的阴性对照）；改完 `.mjs` 必须
  `dev_reload_preset` **且**发生一次真正的重新挂载（#A 节）。
- `make verify` / `make control` 是这条契约的唯一回归面；`make check` 只管部署形态（未部署 = ⓘ）。
- 本 ADR 引用的读数每次都要带「口径 + 窗口 + 日期」；口径本身仍在 #19，别在此处复制。
